Windows beta.
Unblock, then extract.

This early build is not digitally signed, so Windows warns you about it. That is expected. It is shared with you personally; please don’t pass it on.

  1. Unblock the ZIP before you extract it

    Right-click the downloaded ZIP and choose Properties. At the bottom of the General tab, tick Unblock, then click OK. If you don’t see the box, the file is already unblocked.

  2. Extract and open it

    Right-click the ZIP, choose Extract All…, then double-click rc-host.exe in the folder. Nothing is installed; delete the folder to remove it.

    If Windows still shows “Windows protected your PC”, choose More info, then Run anyway.

  3. Sign in once, then share

    The README inside the ZIP shows how to sign this PC in to your SkipperDesk account. After that, give the Device ID and access code to the person connecting, and answer the prompt when they arrive.

You don’t need to change any Windows or antivirus settings. What works on each platform ↗

On a Mac.
A few steps, then you’re home.

  1. Put SkipperDesk in Applications

    Open the downloaded file and drag SkipperDesk into your Applications folder. Install it on the Mac you connect from, and on the Mac you share.

  2. Open it on the Mac you’ll share

    The first time, macOS asks you to confirm the download. Choose Open. SkipperDesk then walks you through two permissions, one at a time.

    If your Mac refuses instead of asking, it is set to allow App Store apps only. Open System Settings › Privacy & Security, scroll to the bottom, and choose Open Anyway.

  3. Sign in and turn on sharing

    On the Mac you connect from, enter the other Mac’s Device ID and access code. No account is needed on that Mac.

Two computers.
One familiar desktop.

Macs need Apple silicon (M1 or later) and macOS 13 Ventura or newer. Intel Macs aren’t supported.

Leaving the other Mac on its own? Turn on Unattended access before you go, so it won’t wait for someone to accept your connection.
